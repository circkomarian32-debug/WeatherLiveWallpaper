# Weather Live Wallpaper — Android

## Можливості
- Автоматичні погодні сцени за координатами телефону через Open-Meteo (без API-ключа).
- Сонце, хмари, дощ, сніг, ніч; анімовані частинки дощу та снігу.
- Пейзажні зображення 1080×1920, створені процедурно. Це художні фони, не фотографії.
- Оновлення даних приблизно раз на 15 хвилин, якщо є доступні координати і мережа.

## Збирання прямо на Android
1. Встановіть AndroidIDE (середовище, що підтримує Gradle Android-проєкти), налаштуйте JDK/SDK за його інструкціями. Потрібні Android SDK Platform 35 і Gradle plugin 8.5.2.
2. Розпакуйте ZIP в локальну папку, відкрийте її в AndroidIDE як Gradle-проєкт.
3. Дочекайтеся синхронізації Gradle та завантаження залежностей через інтернет.
4. Зберіть debug APK (Build → Assemble Debug або Gradle task :app:assembleDebug).
5. Знайдіть app/build/outputs/apk/debug/app-debug.apk, встановіть його.
6. Запустіть застосунок, надайте доступ до місцезнаходження, увімкніть GPS, натисніть «Оновити погоду», потім «Встановити живі шпалери».

## Важливі обмеження
- APK не входить у ZIP: це вихідний проєкт.
- Проєкт не був скомпільований у цьому середовищі, бо Android SDK тут відсутній.
- Для автоматичної геолокації використовується остання доступна системна координата. Якщо її немає, відкрийте карти або іншу програму, яка отримує GPS, потім натисніть «Оновити погоду».
- При недоступній погоді відображається остання сцена або сонячна сцена.
- Живі шпалери витрачають заряд; 30 кадрів/с, анімація лише коли шпалери видимі.
- Якщо AndroidIDE не підтримує цю версію Android Gradle Plugin, налаштуйте відповідні сумісні версії Gradle/AGP/SDK.
